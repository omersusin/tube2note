Tube2Note is a YouTube to text tool for students, researchers, and anyone who works with videos. It turns channels, playlists, or single videos into clean Markdown transcripts with timestamps and chapters. Then you can study them, search them offline, or feed them to AI tools like NotebookLM. If a run gets interrupted it picks up where it stopped. It can watch channels for new uploads, skip sponsor segments, write citations, and export SRT, PDF, EPUB, Anki flashcards, and Obsidian notes. It runs on Android, Windows, Mac, and Linux.

How it works

1. Point

Paste a channel, playlist, or video URL. Guided mode included: just run tube2note.

2. Fetch

Captions, timestamps, and chapters — throttled and resumable.

3. Drop in

Markdown (+ PDF) that NotebookLM accepts as a source.

Built for the NotebookLM cap

One notebook holds ~500,000 words. Stay under it with --split-words 400000, one file per course, and --timestamps for citations.

FAQ

Why not paste links into NotebookLM?

NotebookLM caps linked videos (~100) and needs captions per video. tube2note merges everything you control: timestamps, chapters, per-video files, resume.

What if a video has no captions?

Transcribe mode covers caption-less videos, so the transcript still lands in your Markdown.

Will it get rate-limited?

Runs are throttled, back off politely, and resume cleanly with --resume-last.

Where does the live demo run?

On the developer's phone, handy for a peek. For real work, run the install command above and work locally.
