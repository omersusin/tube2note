tube2note — YouTube to Markdown for NotebookLM

Turn a channel, playlist, or videos into Markdown + PDF ready for NotebookLM / any RAG pipeline. Resumable, polite to rate limits, works in terminal, guided mode, or local web UI.

GitHubPyPI

Install

pip install tube2note
tube2note -o channel.md "https://www.youtube.com/@SomeChannel/videos"
# guided: tube2note
# web UI: tube2note serve
# search: tube2note search "query" -d ./out
Students: one file per course, --split-words 400000 under the 500k NotebookLM cap, --timestamps for citations.
Researchers: --layout tree + INDEX.md, --since YYYY-MM-DD, resume with --resume-last, search offline.

Why not paste links into NotebookLM?

  • Caps (~100 videos), needs captions per video.
  • tube2note merges everything you control: timestamps, chapters, per-video files, resume.
