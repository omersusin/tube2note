tube2note — YouTube → Markdown for NotebookLM

Turn a channel, playlist, or videos into Markdown + PDF files ready for NotebookLM. Single-file Python, resumable, polite to YouTube's rate limits.

GitHub PyPI

Install

pip install tube2note yt-dlp
tube2note -o channel.md "https://www.youtube.com/@SomeChannel/videos"

Why

  • NotebookLM caps YouTube imports (~100 videos) — tube2note merges everything.
  • 500k-word auto-split, timestamps, chapters, per-video files, resume.
  • Guided TUI, web UI, profiles, PDF export, Gemini summaries.
